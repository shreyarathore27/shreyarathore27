## Projects

### [StrokeSure](https://github.com/shreyarathore27/StrokeSure.git)

Stroke prediction under severe class imbalance, run as a controlled comparison rather than a single model. Benchmarks multiple classifiers and imbalance-handling strategies, and evaluates each on calibration, robustness and interpretability as well as discrimination. On rare-event data, accuracy alone is misleading.

`Python` `scikit-learn` `Pandas` `NumPy`

### [PCOSense](https://github.com/shreyarathore27/PCOSense.git)

PCOS risk prediction from clinical and lifestyle features. Compares models by ROC-AUC and uses feature importance to explain which factors drive each prediction.

`Python` `scikit-learn` `Pandas` `NumPy`

### [FlowProof](https://github.com/shreyarathore27/FlowProof.git)

A consent-driven financial intelligence platform. Unifies a user's authorised activity across multiple financial accounts, generates insights from it, and lets the user share verified financial credentials only with organisations they authorise.

`MongoDB` `Express` `React` `Node.js` `ML`

### [Dietly](https://github.com/shreyarathore27/dietly.git)

A full-stack nutrition application combining a frontend, backend and AI features.

`JavaScript` `AI`
